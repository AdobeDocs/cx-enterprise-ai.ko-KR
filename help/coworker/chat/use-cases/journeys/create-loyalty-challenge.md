# Adobe Journey Optimizer 및 Coworker - 충성도 문제 및 지표 통찰력 만들기

이 데모에서는 Adobe Journey Optimizer(AJO) 충성도를 동료에서 사용하여 충성도 프로그램 관리를 간소화하고 가속화하는 방법을 살펴볼 수 있습니다.
