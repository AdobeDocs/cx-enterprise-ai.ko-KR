# 캠페인 중지 {#stop-campaign}

이제 사용자는 캠페인 세부 정보 페이지에서 직접 활발하게 전송(&quot;라이브&quot; 캠페인)하는 캠페인을 중지할 수 있습니다. 캠페인 중지는 영구적입니다. 수신자는 즉시 캠페인 진행을 정지하며 이후에 캠페인을 다시 시작하거나 다시 시작할 수 없습니다.

## 사전 요구 사항

- 캠페인은 라이브(활성 전송) 상태여야 합니다. 초안, 예약됨 또는 이미 중지된 캠페인에는 중지 작업을 사용할 수 없습니다.
- [입력이 필요함 — 엔지니어를 통해 확인하기 위해: 캠페인을 중지하려면 특정 역할이나 권한이 필요합니까? 또는 캠페인 액세스 권한이 있는 사용자가 이 작업을 수행할 수 있습니까?]

## 이 기능의 기능

캠페인이 라이브될 때마다 캠페인 세부 사항 헤더에 &quot;캠페인 중지&quot; 작업이 표시됩니다. 이 옵션을 선택하면 작업이 영구적임을 알리는 확인 대화 상자가 열립니다. 확인하면 백엔드가 캠페인을 중지하도록 호출합니다. 성공 시 캠페인의 상태가 &quot;중지됨&quot;으로 변경되고 확인 메시지가 표시됩니다.

### 주요 동작

- 캠페인 중지 작업은 캠페인이 라이브(활발하게 전송)되는 동안에만 표시됩니다.
- 중지는 영구적입니다. 수신자가 캠페인을 진행하지 않으므로 다시 시작할 수 없습니다.
- 확인 대화 상자를 사용하려면 캠페인이 중지되기 전에 사용자가 명시적으로 확인해야 합니다.
- 중지 후 캠페인의 상태 배지가 &quot;중지됨&quot;으로 업데이트됩니다.
- 중지 요청이 실패하면 오류 메시지가 표시되고 캠페인이 활성 상태로 유지됩니다.

## 사용 방법

1. 현재 라이브(진행 중)인 캠페인을 엽니다.
2. 캠페인 세부 정보 헤더에서 **캠페인 중지**&#x200B;를 클릭합니다.
3. 확인 대화 상자에서 &quot;캠페인 중지는 영구적입니다. 모든 수신자가 진행을 중단하고 캠페인을 다시 시작할 수 없습니다.&quot;
4. 확인하려면 **중지**&#x200B;를 클릭하세요.
5. &quot;캠페인이 중지되었습니다.&quot; 확인 메시지가 나타나고 캠페인의 상태가 &quot;중지됨&quot;으로 업데이트됩니다.

### 입력 필드/매개 변수

적용할 수 없음 — 이 기능은 입력 필드가 없는 단일 확인 작업입니다.

## UI 설명선

> **기술 기록기 참고**: 다음에 필요한 스크린샷:

- [ ] 실시간 캠페인에 표시된 캠페인 세부 정보 헤더의 &quot;캠페인 중지&quot; 단추
- [ ] 영구성 경고가 포함된 확인 대화 상자
- [ ] 성공적으로 중지한 후 &quot;중지됨&quot; 상태 배지
- [ ] 중지가 실패할 경우 표시되는 오류 메시지

## 이 기능에서 수행할 수 없는 작업

- 캠페인을 일시적으로 일시 중지하지 않습니다. 중지된 캠페인을 다시 시작할 방법은 없습니다. 중지는 단방향 작업입니다.
- 동일한 캠페인 레코드에서 중지된 캠페인을 다시 시작하거나 다시 시작할 수 없습니다.
- [입력이 필요함 — 엔지니어를 통해 확인하기 위해: &quot;일시 중지 및 다시 시작&quot; 기능이 별도로 계획되어 있습니까? 아니면 이 릴리스에서 유일한 상태 제어 동작 전송을 중지합니까?]
