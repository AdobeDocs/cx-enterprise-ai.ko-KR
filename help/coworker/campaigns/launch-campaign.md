# 캠페인 실행 {#launch-campaign}

캠페인 시작은 초안 전송에서 활성 전송으로 이동하는 작업입니다. 시작 대화 상자가 열리기 전에 Halo는 캠페인이 준비되었는지 확인하고 필요한 설정이 완료될 때까지 시작을 차단합니다. 론치 대화 상자는 이메일 및 대상자의 미리 보기를 표시하고, 사용자가 전송 일정을 인라인으로 검토하거나 변경할 수 있도록 하며, 론치 성공 여부를 다시 보고합니다. 이 섹션에서는 전체 실행 환경을 다룹니다. 실행 중에 제공되는 일정 옵션에 대해서는 [캠페인 예약](/help/coworker/campaigns/schedule-campaign.md)을 참조하십시오.

## 사전 요구 사항

- 캠페인이 초안 상태여야 합니다. <!-- The Launch action isn't available once a campaign is already live. -->
<!-- - The campaign must pass a readiness check: sending settings configured, at least one test email sent, and a real (non-sample) audience uploaded. -->
- [입력이 필요함 — 엔지니어를 통해 확인하기 위해: 일부 사용자는 인앱 실행 대신 캠페인 다운로드나 증명 이메일 전송만 제공하는 실제 실행 버튼 대신 &quot;출시 예정&quot; 환경을 볼 수 있습니다. 특정 사용자 또는 캠페인이 받게 되는 경험을 결정하는 방법을 확인합니다.]

## 이 기능의 기능

사용자가 캠페인을 시작할 때 Halo는 먼저 캠페인이 준비되었는지 확인합니다. 필요한 항목이 누락된 경우 실행을 계속 진행하기 전에 수정해야 할 사항이 대화 상자에 나열됩니다. 유효성 검사가 성공하면 시작 대화 상자에 이메일 및 대상자/워크플로우의 미리 보기가 표시되고, 사용자가 흐름을 떠나지 않고 전송 일정을 검토하거나 편집할 수 있으며, 대규모 전송을 위해 예상 전송 볼륨 알림이 표시됩니다. 확인하면 시작이 트리거되고, Halo는 시작됨, 이미 시작됨 또는 실패의 세 가지 결과 중 하나를 보고합니다.

### 주요 동작

- 시작은 초안 상태의 캠페인에만 사용할 수 있습니다. 이미 라이브 상태인 캠페인은 다시 시작할 수 없습니다.
- 시작 대화 상자가 열리기 전에 준비 검사가 자동으로 실행됩니다. 해결되지 않은 문제는 시작을 차단하며 각 문제를 해결하는 방법과 함께 나열됩니다.
- 시작 대화 상자에 이메일 미리 보기(제목, 사전 헤더, 발신자) 및 대상자/워크플로우 미리 보기가 표시됩니다.
- 론치 대화 상자 내에서 전송 일정을 검토하거나 변경할 수 있습니다.
- 전송 용량이 큰 경우 대화 상자에 예상되는 전송 볼륨 영향이 표시됩니다. [입력이 필요합니다. 이 알림의 정확한 문구를 코드에서 사용할 수 없습니다.]
- 성공 시 캠페인의 상태가 &quot;예약됨&quot; 또는 &quot;라이브&quot;(선택한 일정에 따라)로 업데이트되고, 확인 메시지에 캠페인 인사이트가 2시간 이내에 제공될 예정입니다.
- 캠페인이 이미 실행된 경우(예: 중복 클릭으로) Halo에는 오류가 아닌 &quot;이미 실행된&quot; 메시지가 표시됩니다.
- 시작이 실패하면 오류 메시지가 나타나고 캠페인이 초안에 유지됩니다. 사용자가 다시 시도할 수 있습니다.
- &#x200B;<!--(see [Stop a live campaign](./stop-live-campaign.md))--> 캠페인이 중지되면 동일한 캠페인 레코드에서 다시 실행할 수 없습니다. 중지하는 것은 별도의 영구 상태입니다.

## 액세스 방법

**캠페인을 시작하려면:**

1. 캠페인에서 **시작**(아직 초안에 있는 동안 &quot;시작 준비 완료&quot;로 표시됨)을 클릭합니다.
2. 누락된 항목이 있는 경우 &quot;몇 가지 사항에 주의가 필요합니다.&quot;라는 대화 상자에 완료해야 할 작업이 나열됩니다.
   - **전자 메일 설정 구성** — 전송 매개 변수(보낸 사람/도메인)가 아직 설정되지 않았습니다.
   - **테스트되지 않은 전자 메일** — 실행 전에 전자 메일을 증명하기 위해 하나 이상의 테스트 전자 메일을 보냅니다.
   - **시작에 필요한 실제 대상** - 캠페인이 아직 샘플 대상을 사용 중입니다. 실제 대상 CSV를 업로드하십시오.
     각 항목을 해결한 다음 Launch를 다시 시도하십시오.
3. 캠페인이 준비 검사를 통과하면 시작 대화 상자가 열리고 이메일 및 대상자의 미리 보기가 표시됩니다.
4. 대화 상자에 표시된 일정을 검토합니다. 변경하려면 [캠페인이 시작될 때 예약](/help/coworker/campaigns/schedule-campaign.md)에 설명된 예약 옵션을 사용한 다음 저장하십시오.
5. 시작을 확인합니다. 성공 시 확인 메시지가 나타나고 캠페인의 상태가 업데이트됩니다(&quot;예약됨&quot; 또는 &quot;라이브&quot;로).

## UI 설명선

> **기술 기록기 참고**: 다음에 필요한 스크린샷:

- [ ] 캠페인 세부 정보 헤더의 시작 진입점/단추
- [ ] 준비/유효성 검사 대화 상자에 불완전한 항목이 나열되어 있습니다.
- [ ] 전자 메일 + 대상 미리 보기 및 일정 섹션을 표시하는 시작 대화 상자
- [ ] 전송 볼륨 영향 예상 알림(대규모 대상의 경우)
- [ ] 실행 후 성공 확인 메시지
- [ ] &quot;이미 시작한&quot; 메시지
- [ ] 일반 실행 실패 오류 메시지

## 이 기능에서 수행할 수 없는 작업

- 샘플(실제로는 아님) 대상자, 테스트되지 않은 이메일 또는 구성되지 않은 전송 설정으로 캠페인 시작을 허용하지 않습니다. 세 가지 모두 먼저 해결해야 합니다.
- 시작을 수행하면 동일한 작업의 일부로 일정이 수락되지 않습니다. 일정은 시작을 확인하기 전 또는 확인하기 위해 동일한 대화 상자 내에서 별도로 저장됩니다.
- 중지된 캠페인의 다시 시작을 지원하지 않습니다. <!--(see [Stop a live campaign](./stop-live-campaign.md))-->에 중지됩니다.
- [입력 필요 — 엔지니어/PM에게 확인: 일부 사용자의 경우, Launch가 인앱 셀프서비스 실행 없이 캠페인 다운로드(PDF/DOCX) 또는 증명 이메일 전송만 제공하는 &quot;출시 예정&quot; 경험으로 대체될 수 있습니다. 해당 집단에 대한 방법 단계를 변경하므로 게시하기 전에 이 대상이 적용되는지 확인하십시오.]
