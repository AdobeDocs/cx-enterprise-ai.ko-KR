# 캠페인 예약 {#schedule-campaign}

이제 사용자는 캠페인을 시작할 때 나갈 시기를 정확하게 선택할 수 있습니다. 즉시, 향후 특정 날짜 및 시간에 또는 반복(반복) 일정에서 선택할 수 있습니다. 사용자는 나중에 다시 와서 이미 시작되었거나 예약된 캠페인의 일정을 변경할 수도 있습니다.

> **변경 내용**: 이전에는 캠페인을 바로 시작할 수 있었습니다. 이 릴리스에는 향후 1회 일정 예약, 반복 일정 및 실행 후 일정 편집 기능이 추가됩니다.

## 사전 요구 사항

- 캠페인을 시작할 준비가 되어 있어야 합니다(모든 필수 설정 완료).
- 시작 가능한 상태에서 캠페인을 보유하는 것 외에 필요한 사전 요구 사항은 없습니다.

## 이 기능의 기능

사용자가 캠페인을 시작할 때 세 가지 예약 모드 중 하나를 선택한 다음 확인합니다. 선택한 일정은 캠페인이 전송을 시작하는 시기 및 반복 캠페인의 경우 반복 빈도 및 종료 시기(또는 종료 여부)를 결정합니다. 캠페인이 예약되거나 라이브되면 캠페인 설정에서 해당 일정을 편집할 수 있습니다.

### 주요 동작

- 시작 시 **지금**, **한 번 예약**, **반복**, 세 가지 예약 모드를 사용할 수 있습니다.
- 향후 예정된 캠페인은 시작 시간이 될 때까지 &quot;예약됨&quot; 상태를 표시한 다음 자동으로 &quot;라이브&quot;로 전환됩니다.
- 시작한 반복 캠페인은 반복 요약과 함께 &quot;라이브&quot;를 표시합니다(예: &quot;매주 화요일, 목요일 오전 9시&quot;).
- 반복 캠페인은 무기한 실행(&quot;종료 안 함&quot;)되거나 특정 종료 날짜까지 실행되도록 설정할 수 있습니다. 일회성 및 즉시 캠페인은 한 번 실행되므로 종료 날짜 옵션이 없습니다.
- 사용자는 캠페인 설정에서 동일한 일정 옵션을 사용하여 이미 시작되었거나 예약된 캠페인의 일정을 편집할 수 있습니다.

## 사용 방법

**시작 시 캠페인을 예약하려면:**

1. 캠페인에서 **시작 준비**&#x200B;를 클릭합니다.
2. 론치 대화 상자에서 일정 옵션을 선택합니다.
   - **지금** — 캠페인은 시작 직후 전송을 시작합니다.
   - **한 번 예약** — 나중에 **시작 날짜**(날짜와 시간 함께)를 선택하세요.
   - **반복** — **빈도**(일별, 주별 또는 월별)와 시작 시간을 선택한 다음 반복 패턴을 설정합니다(아래 필드 참조).
3. [반복]을 선택한 경우 캠페인이 **절대** 또는 **날짜에**&#x200B;로 종료되는지 선택하고 해당하는 경우 종료 날짜를 선택하십시오.
4. 선택한 일정으로 캠페인을 시작할지 확인합니다.

**기존 일정을 편집하려면:**

1. 캠페인을 열고 설정으로 이동합니다.
2. 일정 섹션을 찾아 현재 일정 요약을 선택합니다.
3. 위에서 설명한 것과 동일한 옵션을 사용하여 일정을 업데이트합니다.
4. 변경 사항을 저장합니다.

### 입력 필드/매개 변수

| 필드 | 설명 | 필수? |
| --- | --- | --- |
| 일정 모드 | 지금, 한 번 예약 또는 반복 중 선택 | 예 |
| 시작 날짜 | 캠페인 시작 날짜 및 시간(한 번 예약 모드) | 예, 한 번 예약합니다. |
| 빈도 | 일별, 주별 또는 월별(반복 모드) | 예, 자동연장 |
| 시작 시간 | 반복 캠페인이 전송하는 시간 | 예, 자동연장 |
| 요일 | 캠페인이 반복되는 날짜 | 예, 주별 빈도 |
| 월일 | 캠페인이 반복되는 해당 월의 어느 날 | 예, 월별 빈도의 경우 |
| 캠페인 종료 | 절대 또는 특정 종료 날짜에 | 예, 자동연장 |

## UI 설명선

> **기술 기록기 참고**: 다음에 필요한 스크린샷:

- [ ] 지금/한 번 예약/반복 옵션을 표시하는 시작 대화 상자
- [ ] 날짜 및 시간 선택기를 한 번 예약합니다
- [ ] 반복 옵션: 빈도 선택기, 주별 요일 전환, 월별 요일 그리드
- [ ] &quot;캠페인 종료&quot; 날짜 선택 안 함/날짜 선택
- [ ] 시작 시간을 기다리는 캠페인의 &quot;예약됨&quot; 상태 배지
- [ ] 되풀이 요약이 있는 &quot;라이브&quot; 상태 배지(예: &quot;매주 화요일, 목 오전 9시&quot;)
- [ ] 캠페인 설정의 일정 섹션에 편집 진입점이 표시됩니다.

## 이 기능에서 수행할 수 없는 작업

- &quot;2주마다&quot; 또는 &quot;3일마다&quot;와 같은 사용자 정의 반복 간격은 지원하지 않으며, 표준 일별, 주별 또는 월별 주파수만 사용할 수 있습니다.
- &quot;월의 두 번째 월요일&quot;과 같은 상대적 월별 재발을 지원하지 않습니다. 월별은 특정 월간 날짜만 선택할 수 있습니다.
- **지금** 또는 **한 번 예약** 캠페인에 대한 종료 날짜를 제공하지 않습니다. 종료 날짜는 일회성 캠페인이 정의에 따라 한 번 실행되므로 [반복]을 선택한 경우에만 사용할 수 있습니다.
